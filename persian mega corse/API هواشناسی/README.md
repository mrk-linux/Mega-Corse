
# 🌦️ API داده‌های هواشناسی

یک API مبتنی بر Flask برای دسترسی به داده‌های تاریخی هواشناسی از ایستگاه‌های مختلف. این API نقاط پایانی (endpoints) برای دریافت دمای یک ایستگاه خاص در تاریخ، سال یا تمام داده‌ها فراهم می‌کند.

---

## 🚀 قابلیت‌ها

- نمایش لیست تمام ایستگاه‌های موجود
- دریافت دمای یک ایستگاه در یک تاریخ مشخص
- دریافت تمام داده‌های دمای یک ایستگاه
- دریافت داده‌های سالانه یک ایستگاه

---

## 📁 ساختار پروژه

```
your weather api/
```

## 📡 نقاط پایانی API

### 1. صفحه اصلی (رابط وب)

```
GET /
```

صفحه HTML شامل:
- راهنمای استفاده از API
- لیست تمام ایستگاه‌های موجود

---

### 2. دریافت دما برای ایستگاه و تاریخ مشخص

```
GET /api/v1/<station>/<date>
```

**پارامترها:**
| پارامتر | نوع | توضیح | مثال |
|----------|------|-------------|---------|
| `station` | عدد صحیح | شناسه ایستگاه | `10` |
| `date` | رشته | تاریخ (سال-ماه-روز) | `1988-10-25` |

**مثال درخواست:**
```
http://127.0.0.1:5001/api/v1/10/1988-10-25
```

**پاسخ:**
```json
{
    "station": "10",
    "date": "1988-10-25",
    "temperature": -2.3
}
```

---

### 3. دریافت تمام داده‌های یک ایستگاه

```
GET /api/v1/<station>
```

**پارامترها:**
| پارامتر | نوع | توضیح | مثال |
|----------|------|-------------|---------|
| `station` | عدد صحیح | شناسه ایستگاه | `10` |

**مثال درخواست:**
```
http://127.0.0.1:5001/api/v1/10
```

**پاسخ:** آرایه‌ای از تمام رکوردهای آن ایستگاه
```json
[
    {"DATE": "1988-10-01", "TG": 15},
    {"DATE": "1988-10-02", "TG": 16},
    ...
]
```

---

### 4. دریافت داده‌های سالانه یک ایستگاه

```
GET /api/v1/yearly/<station>/<year>
```

**پارامترها:**
| پارامتر | نوع | توضیح | مثال |
|----------|------|-------------|---------|
| `station` | عدد صحیح | شناسه ایستگاه | `10` |
| `year` | عدد صحیح | سال (۱۲۳۴) | `1988` |

**مثال درخواست:**
```
http://127.0.0.1:5001/api/v1/yearly/10/1988
```

**پاسخ:** آرایه‌ای از رکوردهای آن سال
```json
[
    {"DATE": "1988-01-01", "TG": -5},
    {"DATE": "1988-01-02", "TG": -3},
    ...
]
```

## 📊 فرمت داده‌ها

- مقادیر دما به صورت یک‌دهم درجه سلسیوس ذخیره شده‌اند
- API به طور خودکار مقادیر را بر ۱۰ تقسیم کرده و دمای واقعی را برمی‌گرداند
- شناسه ایستگاه‌ها به صورت ۶ رقمی با صفرهای ابتدایی پر می‌شوند

## 📌 نکات

- شناسه ایستگاه به طور خودکار به ۶ رقم تبدیل می‌شود (مثلاً ایستگاه `1` → `000001`)
- فرمت تاریخ باید `YYYY-MM-DD` باشد
- فرمت سال باید `YYYY` باشد
- دما به درجه سلسیوس برگردانده می‌شود
