
# 📰 ارسال خبر به ایمیل

این اسکریپت پایتون آخرین اخبار را از یک API خبری دریافت کرده و به ایمیل شما ارسال می‌کند.

---

## 🚀 قابلیت‌ها

- دریافت آخرین اخبار از API خبری
- استخراج عنوان و توضیحات اخبار
- ارسال اخبار به ایمیل شما
- محدودیت ۲۰ خبر آخر

---

## 🛠️ پیش‌نیازها

```bash
pip install requests
```

ماژول `send_mail.py` نیز برای ارسال ایمیل نیاز است.

---

## 📝 تنظیمات

1. **دریافت کلید API**  
   در سایت [NewsAPI.org](https://newsapi.org) ثبت‌نام کرده و کلید رایگان دریافت کنید.

2. **به‌روزرسانی URL**  
   آدرس URL را با منبع خبری دلخواه جایگزین کنید.

3. **تنظیمات ایمیل**  
   فایل `send_mail.py` را با اطلاعات ایمیل خود تنظیم کنید.

---

## ▶️ نحوه استفاده

```bash
python main.py
```
