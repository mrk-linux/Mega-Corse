# 🌤️ برنامه پیش‌بینی آب و هوا

یک برنامه وب ساده و تعاملی برای پیش‌بینی آب و هوا که با **Streamlit** و **API اوپن‌وادر** ساخته شده است.  
این برنامه روند دما و وضعیت آسمان را برای هر شهری در ۱ تا ۵ روز آینده نمایش می‌دهد.

---

## 🚀 قابلیت‌ها

- وارد کردن نام هر شهر برای دریافت پیش‌بینی آب و هوا
- انتخاب تعداد روزهای پیش‌بینی (۱ تا ۵ روز)
- انتخاب بین نمایش **دما** یا **وضعیت آسمان**
- نمودار خطی تعاملی برای دما با استفاده از Plotly
- نمایش بصری وضعیت آسمان با آیکون‌های مرتبط

---

## 🔑 تنظیمات API

این برنامه از **[API پیش‌بینی ۵ روزه / ۳ ساعته اوپن‌وادر](https://openweathermap.org/forecast5)** استفاده می‌کند.  
برای استفاده از سرویس به یک کلید API رایگان نیاز دارید.

1. به سایت [OpenWeatherMap API](https://openweathermap.org/api) بروید
2. یک حساب رایگان بسازید
3. به داشبورد خود بروید و کلید API منحصر به فرد خود را کپی کنید
4. متغیر `API_key` را در فایل `backend.py` با کلید خود جایگزین کنید

```python
API_key = "your_api_key_here"
```

---

## ▶️ نحوه استفاده

1. برنامه Streamlit را اجرا کنید:

```bash
streamlit run main.py
```

2. نام یک شهر را وارد کنید (مثلاً `Tehran`، `London`، `Tokyo`)
3. تعداد روزهای پیش‌بینی را انتخاب کنید
4. **Temperature** یا **Sky** را برای مشاهده داده انتخاب کنید

---

## 📡 مرجع API

این برنامه از API Forecast اوپن‌وادر استفاده می‌کند.

| پارامتر | توضیح |
|---------|-------|
| `place` | نام شهر (مثلاً Tehran) |
| `forecast_days` | تعداد روزهای پیش‌بینی (۱ تا ۵) |
| `API_key` | کلید API اوپن‌وادر شما |

**آدرس API:**
```
http://api.openweathermap.org/data/2.5/forecast?q={city}&appid={API_key}
```
