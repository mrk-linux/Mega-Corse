# 📹 تشخیص حرکت با هشدار ایمیل

این پروژه با استفاده از وب‌کم حرکت را تشخیص می‌دهد، هنگام تشخیص حرکت تصویر ذخیره می‌کند و یک ایمیل با تصویر گرفته شده ارسال می‌کند.

---

## 🚀 قابلیت‌ها

- تشخیص حرکت در لحظه با استفاده از OpenCV
- ذخیره تصاویر هنگام تشخیص حرکت
- ارسال ایمیل با تصویر گرفته شده
- نمایش ماسک حرکت و مستطیل دور اشیا
- ساده و آسان برای استفاده

---

## 📁 ساختار پروژه

```
motion-detection/
├── main.py              # اسکریپت اصلی برنامه
├── email_sender.py      # ماژول ارسال ایمیل
├── images/              # پوشه ذخیره تصاویر
│   └── (تصاویر ذخیره شده)
└── README.md
```

---

## 🛠️ پیش‌نیازها

پکیج‌های مورد نیاز را نصب کنید:

```bash
pip install opencv-python
```

### تنظیمات ایمیل

1. **تأیید دو مرحله‌ای** را در حساب جیمیل خود فعال کنید
2. یک **رمز عبور اپلیکیشن** از [Google App Passwords](https://myaccount.google.com/apppasswords) بسازید
3. فایل `email_sender.py` را با اطلاعات خود به‌روز کنید

---

## 📧 تنظیمات ایمیل

در فایل `email_sender.py`، این مقادیر را به‌روز کنید:

```python
PASSWORD = "your_app_password"  # رمز عبور اپلیکیشن جیمیل
SENDER = "your_email@gmail.com" # آدرس ایمیل فرستنده
RECEIVER = "your_email@gmail.com" # آدرس ایمیل گیرنده
```

---

## ▶️ نحوه استفاده

1. مطمئن شوید پوشه `images/` وجود دارد
2. اسکریپت را اجرا کنید:

```bash
python main.py
```

3. برای خروج، کلید `q` را فشار دهید

---

## 📊 نحوه عملکرد

| مرحله | توضیح |
|-------|-------|
| ۱ | دریافت تصویر از وب‌کم |
| ۲ | تشخیص حرکت با مقایسه فریم‌ها با پس‌زمینه |
| ۳ | کشیدن مستطیل سبز دور اشیا متحرک |
| ۴ | ذخیره فریم به عنوان تصویر در پوشه `images/` |
| ۵ | ارسال ایمیل با تصویر گرفته شده پس از توقف حرکت |

---

## 📌 نکات

- اسکریپت تصاویر را در پوشه `images/` ذخیره می‌کند
- فقط تصاویر بزرگتر از ۳۰۰۰ پیکسل معتبر در نظر گرفته می‌شوند (برای کاهش نویز)
- تصویر وسطی از دنباله تصاویر گرفته شده از طریق ایمیل ارسال می‌شود
- آستانه تشخیص حرکت روی ۶۰ تنظیم شده است (قابل تغییر)
