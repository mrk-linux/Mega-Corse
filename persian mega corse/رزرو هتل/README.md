# 🏨 سیستم رزرو هتل

این پروژه یک **سیستم رزرو هتل** است که اطلاعات هتل‌ها، کارت‌های اعتباری و رمزهای عبور امنیتی را از فایل‌های CSV می‌خواند.

---

## 🚀 ویژگی‌ها

- بررسی موجودی هتل از دیتابیس CSV
- رزرو هتل و بروزرسانی وضعیت موجودی
- اعتبارسنجی اطلاعات کارت اعتباری (شماره، تاریخ انقضا، نام دارنده، CVV)
- احراز هویت کارت اعتباری با رمز عبور امنیتی
- تولید رسید رزرو برای مشتری

---

## 📁 ساختار پروژه

```
Hotel_Reservation/
├── hotel_reservation.py   # اسکریپت اصلی
├── hotels.csv             # دیتابیس هتل‌ها
├── cards.csv              # اطلاعات کارت‌های اعتباری
└── card_security.csv      # رمزهای عبور امنیتی کارت‌ها
```

---

## 🛠️ پیش‌نیازها

نصب پکیج مورد نیاز پایتون:

```bash
pip install pandas
```

---

## 📝 فرمت فایل‌های CSV

### `hotels.csv`

| ستون        | توضیح                             |
|-------------|-----------------------------------|
| `id`        | شناسه هتل (رشته)                  |
| `name`      | نام هتل                           |
| `available` | وضعیت موجودی (بله/خیر)           |

### `cards.csv`

| ستون        | توضیح                             |
|-------------|-----------------------------------|
| `number`    | شماره کارت اعتباری (رشته)         |
| `expiration`| تاریخ انقضا (ماه/سال)             |
| `holder`    | نام دارنده کارت                   |
| `cvc`       | کد امنیتی (رشته)                 |

### `card_security.csv`

| ستون        | توضیح                             |
|-------------|-----------------------------------|
| `number`    | شماره کارت اعتباری (رشته)         |
| `password`  | رمز عبور امنیتی                  |

---

## ▶️ نحوه استفاده

اجرای اسکریپت از ترمینال:

```bash
python hotel_reservation.py
```

شناسه هتل مورد نظر را وارد کنید. سیستم موارد زیر را انجام می‌دهد:

1. بررسی موجود بودن هتل
2. اعتبارسنجی کارت اعتباری (نمونه hardcoded)
3. احراز هویت رمز عبور
4. رزرو هتل
5. تولید رسید رزرو

---

## 🧠 نحوه عملکرد

1. خواندن اطلاعات هتل‌ها از فایل `hotels.csv` با استفاده از Pandas
2. کاربر شناسه هتل را وارد می‌کند
3. بررسی موجود بودن هتل
4. اعتبارسنجی اطلاعات کارت اعتباری از فایل `cards.csv`
5. احراز هویت رمز عبور از فایل `card_security.csv`
6. بروزرسانی وضعیت هتل به "no" و ذخیره در فایل CSV
7. تولید رسید رزرو با نام مشتری

---

## 📌 نکات

- شماره کارت و رمز عبور برای نمایش در کد **hardcoded** شده‌اند
- این کد صرفاً برای **اهداف آموزشی** نوشته شده است
- از این کد در محیط تولید (Production) استفاده نکنید
- می‌توانید فایل‌های CSV را برای افزودن هتل‌ها یا کارت‌های بیشتر ویرایش کنید
