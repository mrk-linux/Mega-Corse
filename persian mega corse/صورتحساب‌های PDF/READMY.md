# 📑 تولید فاکتور PDF از اکسل

این اسکریپت پایتون فایل‌های اکسل فاکتور (`.xlsx`) را به فاکتورهای PDF حرفه‌ای تبدیل می‌کند.

---

## 🚀 قابلیت‌ها

- خواندن همه فایل‌های اکسل از پوشه `Invoices/`
- استخراج شماره فاکتور و تاریخ از نام فایل
- ایجاد PDF فرمت‌شده با:
  - شماره فاکتور و تاریخ
  - جدول محصولات (شناسه محصول، نام، تعداد، قیمت واحد، قیمت کل)
- ذخیره هر PDF در پوشه `Pdfs/`

---

## 📁 ساختار پروژه

```
project/
├── Invoices/          # فایل‌های اکسل را اینجا قرار دهید
│   ├── 101-2025.xlsx
│   └── 102-2025.xlsx
├── pdfs/              # فایل‌های PDF ساخته شده در اینجا ذخیره می‌شوند
|   ├── 101-2025.pdf
|   ├── 102-2025.pdf
├── main.py            # اسکریپت اصلی
└── README.md
```

---

## 📝 فرمت فایل اکسل

فایل اکسل شما باید دارای ستون‌های زیر باشد:

| نام ستون           | توضیحات                  |
|--------------------|--------------------------|
| `product_id`       | شناسه محصول              |
| `product_name`     | نام محصول                |
| `amount_purchased` | تعداد خریداری شده        |
| `price_per_unit`   | قیمت هر واحد             |
| `total_price`      | قیمت کل محصول            |

### نحوه نام‌گذاری فایل

فایل‌های اکسل خود را به صورت زیر نام‌گذاری کنید:  
`{شماره_فاکتور}-{تاریخ}.xlsx`

مثال‌ها:
- `101-2025-01-15.xlsx`
- `102-2025-01-20.xlsx`

## 🛠️ پیش‌نیازها

پکیج‌های مورد نیاز را نصب کنید:

```bash
pip install pandas fpdf
```

---

## ▶️ نحوه استفاده

1. فایل‌های `.xlsx` خود را در پوشه `Invoices/` قرار دهید
2. اسکریپت را اجرا کنید:

```bash
python main.py
```

3. فاکتورهای PDF خود را در پوشه `Pdfs/` مشاهده کنید

---

## 🧠 نحوه عملکرد

1. اسکریپت پوشه `Invoices/` را برای همه فایل‌های `.xlsx` بررسی می‌کند
2. برای هر فایل:
   - داده‌های اکسل را می‌خواند
   - یک صفحه PDF جدید ایجاد می‌کند
   - شماره فاکتور و تاریخ را از نام فایل استخراج می‌کند
   - جدول اطلاعات محصولات را اضافه می‌کند
   - PDF را در پوشه `Pdfs/` ذخیره می‌کند

---

## 📌 نکات

- پوشه `Pdfs/` در صورت نبودن به صورت خودکار ساخته می‌شود
- نام ستون‌ها به صورت خودکار تمیز می‌شوند (خط تیره به فاصله و حروف بزرگ)
