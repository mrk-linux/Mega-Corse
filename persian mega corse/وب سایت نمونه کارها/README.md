#  نمونه کارهای شخصی

این یک **وبسایت نمونه کار شخصی با Streamlit** است که مهارت‌ها، پروژه‌ها و معرفی من را به عنوان یک توسعه‌دهنده پایتون نمایش می‌دهد.

---

## 🚀 قابلیت‌ها

- چیدمان تمیز و حرفه‌ای با دو ستون
- معرفی شخصی و تصویر پروفایل
- نمایش پروژه‌ها به صورت کارت‌های جداگانه شامل:
  - عنوان پروژه
  - توضیحات
  - پیش‌نمایش تصویر
  - لینک سورس کد
- تقسیم پروژه‌ها در دو ستون برای خوانایی بهتر

---

## 📁 ساختار پوشه

```
your_project/
├── main.py                # برنامه اصلی Streamlit
├── data.csv               # اطلاعات پروژه‌ها (عنوان، توضیحات، تصویر، آدرس)
├── image/
│   ├── me.jpg             # تصویر پروفایل
│   └── project_images/    # تصاویر پروژه‌ها
└── README.md
```

---

## 📄 فرمت فایل data.csv

فایل `data.csv` باید شامل ستون‌های زیر باشد (جداکننده: `;`):

| ستون          | توضیح                              |
|---------------|------------------------------------|
| `title`       | عنوان پروژه                        |
| `description` | توضیحات کوتاه پروژه                |
| `image`       | نام فایل تصویر (در پوشه `image/`)  |
| `url`         | لینک سورس کد (گیت‌هاب و غیره)      |

**مثال:**
```csv
title;description;image;url
برنامه آب و هوا;دریافت اطلاعات آب و هوای زنده;weather.png;https://github.com/...
برنامه لیست کارها;اپلیکیشن مدیریت وظایف;todo.png;https://github.com/...
```

برنامه را اجرا کنید:

```bash

```

## 📌 نکات

- تصاویر باید در پوشه `image/` قرار داشته باشند
- فایل `data.csv` باید با جداکننده `;` (سمی‌کالن) ذخیره شود
- تصویر پروفایل با عرض ۶۰۰ پیکسل نمایش داده می‌شود
